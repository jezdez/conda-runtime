> [!IMPORTANT]
> Existing Windows alpha installations cannot update in place to this release.
> Move aside the existing executable and managed prefix, then install this
> release into a fresh prefix. Do not reuse the old direct-install metadata.

This release rebuilds all five native executables with conda-ship 0.9.0 and
publishes every native update package under `conda-runtime`.

The macOS artifacts pass strict native signature validation. The Windows
runtime data uses the `.cship` anchor that can be covered by a downstream
Authenticode signature.

The Windows update proof exercises a conda-ship 0.9.0 runtime updating to a
second conda-ship 0.9.0 runtime through `conda-runtime`. Windows installations
built with the earlier runtime-data format require the fresh installation
described above.
