> [!IMPORTANT]
> Existing Windows alpha installations cannot update in place to this release. Move aside the existing executable and managed prefix, then install this release into a fresh prefix. Do not reuse the old direct-install metadata.

- Update the bundled conda to 26.9.1 and refresh the runtime package locks for all six platforms.
- Bundle conda-self 0.3.0, conda-pypi 0.13.0, conda-lockfiles 0.2.2, conda-rattler-solver 0.2.0, and packaging 26.3 to match conda's updated requirements.
- Include conda-launchers 24.7.1 in the Windows runtime for conda's native entry-point launchers.
- Keep conda-runtime-updater 0.1.0 and build the native executables with conda-ship 0.10.0.
- Add native Windows ARM64 executables and update packages with Python 3.14. The Windows installer selects the executable for the operating system architecture. Other platforms continue to use Python 3.12.
